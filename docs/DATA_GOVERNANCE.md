# Gouvernance des données

- Collecter uniquement des documents institutionnels publics.
- Conserver URL, date de collecte, hash SHA-256, catégorie et statut temporel.
- Statuts recommandés : `current`, `archived`, `unknown`, `superseded`.
- Ne jamais assimiler `unknown` à `current`.
- Exclure les données personnelles, notes, listes nominatives et documents derrière authentification.
- Vérifier les conditions de réutilisation et ne pas redistribuer les fichiers sans autorisation.
- Pour une réponse liée à une procédure actuelle, privilégier une source datée et confirmée.
- Si deux sources se contredisent, signaler la contradiction plutôt que choisir arbitrairement.
